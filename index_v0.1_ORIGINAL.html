Project Structure & README

This project compiles the full SetupScore stack into a single file with native mobile camera support, vision AI parsing, LocalStorage caching, and side-by-side setup comparisons.

📄 index.html

Contains all HTML screens, Tailwind responsive components, and bottom mobile navigation.

🎨 style.css

Embedded glassmorphism design tokens, keyframe animations, circular gauge styles, and dark aesthetics.

⚡ app.js

Handles Gemini 3 Flash Vision API prompt payload, image base64 conversion, standard LocalStorage history, and score comparison engine.
